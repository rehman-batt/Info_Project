# 🔐 Secure Encrypt

A simple Flask-based web application for generating RSA key pairs, encrypting, and decrypting text using those keys. This tool demonstrates fundamental cryptography operations with a clean, responsive frontend.

## 🚀 Features

- Generate RSA public/private key pairs
- Encrypt plain text using the public key
- Decrypt encrypted text using the private key
- User-friendly interface with real-time operations
- Security best practices:
  - HTTP security headers via `Flask-Talisman`
  - Input validation and error handling
  - No raw stack traces exposed to users

## 🛠️ Tech Stack

- **Backend**: Python, Flask, Cryptography
- **Frontend**: HTML, CSS, JavaScript
- **Security**: Flask-Talisman, input sanitization
